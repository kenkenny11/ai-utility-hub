# AI Utility Hub

A clean, mobile-first collection of practical browser-based AI utility tools.

## Current tools
- YouTube Title Generator
- Social Caption Generator
- Product Description Generator
- Blog Outline Generator
- AI Prompt Generator
- SEO Meta Description Generator

## Architecture
The current version is static and safe for GitHub Pages. It does not expose a Gemini API key in browser code. A future Gemini-backed version should use a server-side function.
